Nav2 Global Planner#

geodex_nav2_planner is a global planner plugin for Nav2. It plans a path on \(\mathrm{SE}(2)\) for the robot’s footprint, under a metric that weights forward, sideways and turning motion. In this guide, we plan a path for a Clearpath Jackal between the desks of an office, and plan again for a holonomic base.

1. Build the plugin#

git clone https://github.com/utiasSTARS/geodex_nav2_planner.git
cd geodex_nav2_planner
pixi run -e jazzy build

See ROS 2 for the build in a colcon workspace.

2. Launch the demo#

The launch starts a map server with the office map, a planner server with the plugin and the Jackal’s parameters, and RViz.

pixi shell -e jazzy
source install/jazzy/setup.bash
ros2 launch geodex_nav2_planner office.launch.py robot:=jackal rviz:=true

3. Request a path#

In a second shell of the same environment, send the request.

ros2 run geodex_nav2_planner office_plan.py

It prints the result, and RViz shows the path of the figure at the top.

error_code=0 poses=6615 length=14.421 m planning_time=34 ms
34 ms

planning time

1000

iterations

14.42 m

path length

The time is from an Intel Core i7-10875H. The demo sets a seed, the iteration budget and the planner’s range. Request the path again and you get the same poses.

config/office.yaml#
planner_server:
  ros__parameters:
    GridBased:
      seed: 1
      refine_iterations: 1000
      range: 10.5
      solve_time: 60.0
      refine_time: 60.0
      publish_footprints: true
      marker_spacing: 0.8
      marker_z: 0.02

4. Try it: plan for a Dingo-O#

Stop the launch, start it again with robot:=dingo_o, and request the path again.

ros2 launch geodex_nav2_planner office.launch.py robot:=dingo_o rviz:=true
ros2 run geodex_nav2_planner office_plan.py

error_code=0 poses=898 length=14.573 m planning_time=28 ms

Only the robot file changes. The Dingo-O’s file sets equal forward and sideways weights, and its footprint slides sideways up the aisle where the Jackal turns and drives forward.

Switch the metric per robot#

The metric weights wx, wy and wtheta weigh forward, sideways and turning motion. Use a large sideways weight, 50 by default, for a differential-drive or skid-steer base, and equal forward and sideways weights for a holonomic base. For a holonomic base, also set max_reverse_run: -1.0. The plugin’s config/robots has a file for each of four Clearpath bases.

The planner checks the footprint against the lethal cells of the global costmap. The costmap does not need an inflation layer.

Visualization#

With publish_footprints: true, the plugin publishes the footprint outline and an orientation frame at poses along the path, as a visualization_msgs/MarkerArray on /planner_server/<plugin name>/path_footprints. marker_spacing sets the distance between the markers.

Parameter

Type

Default

Range

Description

collision_check_resolution

double

0.0

0.0 to 1.0

Spacing of motion checks in meters, or 0 for the costmap resolution.

safety_margin

double

0.0

0.0 to 0.5

Clearance in meters that every lethal cell center keeps from the footprint outline along the whole path, where half a cell diagonal (resolution / sqrt(2)) keeps the footprint off every lethal cell square.

footprint_samples_per_edge

int

8

1 to 64

Minimum number of samples per footprint edge, which the checker raises until samples are at most one cell apart.

lethal_cost_threshold

int

254

1 to 254

Costmap cost at or above which a cell is an obstacle, with unknown cells (255) always obstacles.

max_reverse_length

double

-1.0

-1.0 to 5.0

Per-edge budget of backward motion in meters during the search, where 0 forbids backward motion and a negative value disables the check.

initial_path

bool

false

With max_reverse_length set, first find a path without the reverse budget and start the constrained search from its greedy cost.
Direction stage#

Parameter

Type

Default

Range

Description

max_reverse_run

double

0.2

-1.0 to 5.0

Limit in meters on the backward run of the smoothed path outside the start and goal allowances, or negative to switch off the direction stage. The direction stage runs after the search and turns backward runs into forward driving (forward_repair). A run that the repair cannot turn stays in the path, and the smoother does not lengthen it.

reverse_allow_start

double

1.0

0.0 to 10.0

Path length in meters from the start within which backward driving is free.

reverse_allow_goal

double

1.0

0.0 to 10.0

Path length in meters before the goal within which backward driving is free.

forward_repair

bool

true

Turn backward runs of the raw path into forward driving with a spin in place at each end.

reverse_spin_cost

double

0.5

0.05 to 10.0

Meters of backward driving that one spin in place is worth, where a run is turned only when it is longer than two spins.

Smoothing#

Parameter

Type

Default

Range

Description

smoothing_enabled

bool

true

Smooth the path on the planning metric, and publish the unsmoothed path when the smoothed path fails the collision or backward-driving checks of the search.

smoothing_output_spacing

double

0.1

0.0 to 2.0

Longest step between the smoother’s returned waypoints, as the coordinate norm of the SE(2) twist, or 0 for no limit. The waypoints lie at equal steps between the corners the smoother keeps, within smoothing_corner_tolerance of the smoothed path.

smoothing_round_corners

bool

true

Round each corner of the smoothed path into a twice continuously differentiable curve that leaves and joins its two edges tangentially, or keep every corner when false.

smoothing_corner_tolerance

double

0.0001

1e-06 to 0.1

Largest distance between a rounding curve and the edges between its samples, and between the smoothed path and its evenly spaced edges, in the coordinate norm of the SE(2) twist. A corner stays sharp when its rounding curve would lie within this distance of the corner. A larger value gives a longer step between the returned waypoints.

smoothing_corner_max_angle

double

π/2

0.0 to π

Largest turning angle in radians of a rounded corner, measured under the planning metric, pi/2 (90 degrees) by default. A corner that turns further, such as a reversal, stays a cusp.
